Fontes e critérios

TACO / NEPA-UNICAMP via API estática de brolesi/taco; dados de produtos via Open Food Facts (ODbL). Valores externos podem estar incompletos e devem ser conferidos com o rótulo.

Unidades nutricionais internas: valores por 100 g; sódio e minerais em mg; vitaminas conforme unidade indicada. Não se presume zero para campos ausentes.
